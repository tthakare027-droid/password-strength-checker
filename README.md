# Password Strength Checker

A simple Python tool that checks how strong a password is and gives tips to improve it.

## Features
- Checks password length
- Checks uppercase, lowercase, numbers and symbols
- Detects very common passwords
- Gives clear improvement tips

## How to run
1. Install Python 3
2. Run: `python checker.py`
3. Enter a password to test

## What I learned
- Python basics and functions
- Regular expressions (regex)
- Why strong passwords matter in cyber security
